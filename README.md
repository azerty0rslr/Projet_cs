# Projet C#

**Nom :** ROUSSELIERE    
**Prénom :** Manon  
**Classe :** B2  
**École :** Sup de Vinci - Nantes  

## Description du projet

Ce projet en C# permet de lire un fichier CSV contenant des informations sur des personnes, de les ajouter à une classe, puis d'afficher les élèves venant de Nantes 
dont la taille est supérieure à la moyenne de la classe, triés par ordre décroissant de taille.
